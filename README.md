# blokvolt.com

English regional guide to EV charging in Serbia and the Western Balkans, served by GitHub Pages (custom domain blokvolt.com).

This repository holds the built site only. Pages are generated by `scripts/gen_com.py` in [hemptoon/blokvolt-rs](https://github.com/hemptoon/blokvolt-rs) from `content/com/` — edit the data there, rebuild and upload; do not edit the HTML here by hand. Procedure: `docs/RUNBOOK.md`, section 3.10.
